# LuxeBite Dashboard

Premium dark-mode glassmorphism food & drink ordering dashboard, mobile-first and fully responsive for phone, tablet, laptop, and large desktop.

## Features

- Responsive SaaS-style UI with desktop sidebar + mobile floating bottom nav.
- Glassmorphism surfaces (blur, translucent layers, white/10 borders, soft shadows).
- Blue + amber radial background glows with subtle SVG noise texture.
- Product cards for drink and food.
- Add-to-cart, item count, subtotal, delivery fee, and total amount.
- Checkout form with delivery details and bank payment instruction:
  - **ABA: 500393771**
- Accessible focus states and reduced-motion support.

## Run locally

Open `index.html` in your browser.

## Automatic deployment to GitHub Pages

This repo includes `.github/workflows/deploy.yml` for automatic deployment.

1. Push to `main` (or `master`).
2. In GitHub repo settings, ensure **Pages** source is **GitHub Actions**.
3. The workflow deploys your site automatically on every push.

Your hosted URL will be:
`https://<your-username>.github.io/<repo-name>/`
